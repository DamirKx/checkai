# CheckAI — Система оптического анализа и структурирования кассовых чеков

Автономный сервис на базе искусственного интеллекта для автоматического извлечения товаров, цен, количества, реквизитов организации и итоговой суммы из фотографий и сканов кассовых чеков.

## Описание проекта

Обработка бумажных и электронных кассовых чеков вручную требует значительных временных затрат и подвержена человеческим ошибкам. **CheckAI** автоматизирует этот процесс:

1. Выполняет оптическое распознавание текста (OCR) с использованием свёрточных и рекуррентных нейросетей.
2. Фильтрует типографский и оптический шум (шапка чека, адреса, реквизиты терминала).
3. Извлекает товарные позиции с разделением на наименование, количество, цену за единицу и общую стоимость.
4. Рассчитывает контрольную сумму и валидирует её относительно итоговой строки чека.
5. Предоставляет результат в виде структурированного JSON-объекта и интерактивного веб-интерфейса.

---

## Ключевые возможности

- **Автономность и безопасность**: Распознавание выполняется локально без отправки конфиденциальных данных и чеков во внешние облачные API.
- **Устойчивость к шуму**: Алгоритмический парсер отделяет метаданные магазина и терминала от непосредственно товарных позиций.
- **Поддержка валюты тенге (₸)**: Корректная обработка национального формата цен и сумм.
- **Два режима работы**: Быстрый CLI-скрипт для пакетной обработки и современный веб-интерфейс с поддержкой Drag & Drop.
- **Экспорт данных**: Мгновенное скачивание результата в формате `.json` или копирование в буфер обмена в один клик.

## Архитектура решения

Пайплайн обработки чека состоит из трёх последовательных этапов:

```
[ Изображение чека ] 
         │
         ▼
[ 1. Модуль нейросетевого OCR (PaddleOCR v3 / PaddleX) ]
  • Детекция текстовых областей (PP-OCRv5 Server Det)
  • Классификация ориентации строк (PP-LCNet Textline Ori)
  • Распознавание кириллических и латинских символов (eslav PP-OCRv5 Mobile Rec)
         │
         ▼
[ 2. Модуль нормализации и парсинга (parser.py) ]
  • Склейка разорванных строк
  • Регулярные выражения для цен: (Цена × Кол-во = Сумма)
  • Извлечение организации, даты и времени
  • Фильтрация адресов и служебных реквизитов (СНО, ФН, ФД, ФП)
         │
         ▼
[ 3. Слой представления (FastAPI + Web UI / JSON) ]
  • REST API эндпоинты
  • Табличный веб-интерфейс (Plus Jakarta Sans + JetBrains Mono)
  • Структурированный JSON
```

## Стек технологий

- **Язык программирования**: Python 3.12
- **Компьютерное зрение и OCR**: PaddleOCR (PaddlePaddle Engine, PaddleX 3.0)
- **Обработка изображений**: OpenCV, NumPy
- **Бэкенд-фреймворк**: FastAPI, Uvicorn, Python-Multipart
- **Фронтенд**: HTML5, Tailwind CSS, JavaScript (Vanilla, без сторонних фреймворков)
- **Типографика**: Plus Jakarta Sans, JetBrains Mono

## Структура репозитория

```
CheckAI/
├── main.py            # Модуль запуска нейросети OCR и консольный интерфейс
├── parser.py          # Логика извлечения позиций, дат, сумм и реквизитов
├── server.py          # Веб-сервер FastAPI и встроенный веб-интерфейс
├── test_ocr.py        # Диагностический скрипт для отладки слоёв OCR
├── images.jpeg        # Тестовый кассовый чек для проверки пайплайна
├── images_result.json # Пример сформированного JSON-файла
├── README.md          # Документация проекта
└── PRESENTATION.md    # Материалы и структура для презентации проекта
```

### 2. Веб-интерфейс (FastAPI)

Для запуска локального сервера с графическим интерфейсом:

```powershell
python server.py
```

После запуска перейдите в браузере по адресу:

```
http://127.0.0.1:8000
```

В интерфейсе доступны:

- Кнопка **«Тестовый чек images.jpeg»** для моментальной проверки работы сервиса.
- Зона **Drag & Drop** и выбор любого файла изображения чека.
- Карточки организации, даты и времени.
- Детализированная таблица позиций с ценами в тенге (₸).
- Кнопки экспорта **«Скачать JSON»** и **«Копировать»**.
- Аккордеон с просмотром сырых строк OCR для аудита распознавания.

## Спецификация API

### 1. Анализ произвольного файла чека

- **URL**: `/api/analyze`
- **Метод**: `POST`
- **Тип содержимого**: `multipart/form-data`
- **Параметры**:
  - `file`: бинарный файл изображения (`image/jpeg`, `image/png`, `image/webp`).

### 2. Экспресс-тест локального чека

- **URL**: `/api/analyze-test`
- **Метод**: `POST`
- **Описание**: Запускает распознавание предустановленного файла `images.jpeg` в корне проекта.

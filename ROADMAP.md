# CheckAI — что доделать

Список задач по ролям, чтобы проект стабильно работал. Составлен по состоянию `main` на 09.10.2026 (после PR #6).
Приоритеты: **P0** — без этого проект работает с ошибками или не запускается у новичка, **P1** — нужно для нормальной работы, **P2** — улучшения.

Как запускать проект под каждую роль — в [TEAM_GUIDE.md](TEAM_GUIDE.md).

## Бэкенд

**P0**
- [x] `PATCH /api/auth/me` — смена имени, email, пароля. Фронт уже ждёт этот эндпоинт, контракт описан в README («Аккаунт пользователя»). Неверный текущий пароль — `400`, не `401`.
- [x] `DELETE /api/auth/me` — удаление аккаунта с паролем. Удалять и файлы фото его чеков из `data/receipts`.
- [x] Ошибки валидации отдавать без технической приставки: сейчас пользователь видит «Value error, Пароль должен содержать минимум 8 символов».

**P1**
- [x] Очистка «осиротевших» фото: файлы, которые распознали, но так и не сохранили в чек (например, гости), копятся в `data/receipts` навсегда. Фоновая задача или удаление при старте файлов старше суток без записи в БД.
- [x] `PUT /api/receipts/{id}` — редактирование сохранённого чека (магазин, дата, позиции, категории). Без этого ошибку распознавания не исправить.
- [x] `GET /api/receipts/{id}` — один чек, чтобы фронт не грузил всю историю ради карточки.
- [x] Фильтры и пагинация на сервере: `GET /api/receipts?from=&to=&category=&q=`. Сейчас фронт тянет до 100 чеков и фильтрует сам — у активного пользователя история обрежется.
- [x] Ограничение частоты запросов на `/api/auth/login`, `/api/auth/register` и `/api/analyze` (перебор паролей, перегрузка OCR).
- [x] Короче срок жизни токена (сейчас 60 мин) + refresh-токен.
- [x] Старые чеки с путём фото вида `/data/receipts/<uuid>_<имя>.jpg`: при удалении чека файл не удаляется (не проходит `IMAGE_PATH_RE`). Миграция путей или поддержка старого формата.

**P2**
- [ ] Очередь распознавания (RQ / Celery / `BackgroundTasks` + статус задачи). Сейчас OCR и запрос к Qwen идут под одной блокировкой — пока один чек распознаётся, остальные пользователи ждут.
- [ ] Health-check `GET /api/health` с состоянием БД, OCR и Ollama — для Docker и мониторинга.
- [ ] Сброс пароля по email.
- [ ] Переход на PostgreSQL для продакшена (Alembic уже готов к этому).

## Зависимости между задачами

- Редактирование чека: бэк `PUT /api/receipts/{id}` → фронт форма редактирования → QA тесты.
- Профиль: бэк `PATCH/DELETE /api/auth/me` → фронт уже готов → QA проверяет.
- Качество распознавания: ML эталоны и скрипт оценки → QA прогон перед релизом → PM решает, достаточно ли.
- Категории: PM список → ML категоризация → бэк хранит → фронт показывает.

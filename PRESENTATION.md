# Презентация проекта CheckAI (Краткая версия)

Краткий сценарий выступления на 2–3 минуты с фокусом на **функционале** сервиса и **принципе его работы**.

---

## Слайд 1. Что такое CheckAI

**Тезисы:**

- **CheckAI** — автономный сервис для мгновенного анализа кассовых чеков с помощью компьютерного зрения.
- Превращает обычную фотографию или скан помятого бумажного чека в чистые структурированные данные.
- Работает полностью локально: без сторонних платных API и без риска утечки финансовой информации.

> **Слова спикера:**  
> «CheckAI решает проблему ручного ввода чеков в финансовые и учётные системы. Пользователь просто загружает фото, а система за секунду извлекает из него товары, цены, дату и общую сумму в машиночитаемом формате.»

---

## Слайд 2. Функционал сервиса

**Что умеет система:**

1. **Распознавание реквизитов**: автоматически определяет название магазина или организации, дату и точное время покупки.
2. **Детализация товарных позиций**: для каждого товара извлекается:
   - Полное наименование (даже если оно занимает 2–3 строки).
   - Количество (в штуках или долях).
   - Цена за единицу.
   - Итоговая стоимость позиции.
3. **Расчёт и контроль суммы**: считает и проверяет общую сумму к оплате в национальной валюте — **тенге (₸)**.
4. **Удобный веб-интерфейс**:
   - Загрузка через Drag & Drop или выбор из проводника.
   - Кнопка экспресс-теста для быстрой проверки.
   - Интерактивная таблица товаров и карточки метаданных.
   - Экспорт в `.json` и быстрое копирование в буфер обмена.
5. **REST API**: эндпоинты для бесшовной интеграции с 1С, ERP или мобильными приложениями.

> **Слова спикера:**  
> «Сервис не просто считывает текст, а понимает структуру чека: отделяет служебные адреса и фискальные номера от реальных покупок, выстраивает аккуратную таблицу товаров с ценами в тенге и позволяет выгрузить готовый JSON в один клик.»

---

## Слайд 3. Как это работает (Пайплайн обработки)

Обработка происходит в 4 последовательных шага:

```
[ 1. Загрузка фото ]
         │
         ▼
[ 2. Компьютерное зрение (PaddleOCR v3) ]
  • Поиск текстовых блоков на изображении (детекция)
  • Автовыравнивание строк под углом
  • Распознавание символов кириллицы и чисел
         │
         ▼
[ 3. Интеллектуальный парсер (parser.py) ]
  • Склейка разорванных строк наименований
  • Отсечение шума шапки (кавычки, юрлица, адреса)
  • Извлечение формулы: [Цена] × [Кол-во] = [Сумма]
  • Поиск итоговой строки чека
         │
         ▼
[ 4. Вывод данных ]
  • Интерактивная таблица в браузере
  • Структурированный JSON через REST API
```

> **Слова спикера:**  
> «Под капотом архитектура делится на два этапа. Сначала нейросеть PaddleOCR v3 находит и распознаёт весь текст на фото. Затем наш алгоритмический парсер очищает данные: отсекает адреса и номера терминалов, склеивает названия товаров, сопоставляет формулу "цена умножить на количество" и проверяет итоговый баланс.»

## Слайд 4. Стек технологий

- **Ядро OCR**: нейросетевая модель PaddleOCR v3 (PaddleX), локальный запуск.
- **Бэкенд**: Python 3.12, FastAPI, асинхронный сервер Uvicorn.
- **Интерфейс**: современный легковесный веб-клиент на Tailwind CSS, адаптивный под мобильные устройства и десктоп.

> **Слова спикера:**  
> «Мы используем локальный нейросетевой OCR-движок и легковесный бэкенд на FastAPI. Это даёт скорость обработки 1–2 секунды на чек и полную независимость от интернета и внешних провайдеров.»
